# 📖 Project Overview

The **EV Market Intelligence Dashboard** is an interactive Power BI project designed to analyze **Electric Vehicle (EV)** registrations across the United States.

The dashboard transforms raw data into meaningful business insights using dynamic KPIs, interactive filters, and engaging visualizations. It enables users to identify market trends, compare manufacturers, evaluate vehicle types, and explore state-wise EV adoption.

# ✨ Dashboard Features

- ⚡ Plug-in Hybrid Electric Vehicle (PHEV) Analysis
- 📈 EV Growth Trend
- 🌍 State-wise EV Distribution
- 🏭 Top Manufacturers
- 🚘 Top Vehicle Models
- 🎯 CAFV Eligibility Analysis

  - Manufacturer
  - Vehicle Type

# 📈 Business Insights

✅ Battery Electric Vehicles account for nearly **66%** of all registrations.

✅ Plug-in Hybrid Vehicles contribute around **34%**.

✅ Tesla is the leading EV manufacturer.

✅ California records the highest EV registrations.

✅ EV adoption has shown steady growth over recent years.
