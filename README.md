# ⚡ EV Market Intelligence Dashboard

An interactive **Power BI dashboard** developed to analyze Electric Vehicle (EV) registrations across the United States. This dashboard provides insights into EV growth, vehicle types, manufacturers, CAFV eligibility, and state-wise distribution using interactive visualizations.

## 📌 Project Overview

This project transforms raw Electric Vehicle registration data into meaningful business insights through Power BI. The dashboard enables users to explore trends using dynamic filters and interactive visualizations.

---

## 📊 Key Performance Indicators (KPIs)

- 🚗 Total EV Registrations: **18K**
- 🔋 Battery Electric Vehicles (BEV): **12K**
- ⚡ Plug-in Hybrid Electric Vehicles (PHEV): **6.2K**
- 📏 Average Electric Range: **33 Miles**
- 🏭 Total Manufacturers: **49**
- 🌎 Total States: **12**

---

## 📈 Dashboard Features

- EV Growth Over Time
- Vehicle Type Distribution
- Top 10 EV Manufacturers
- State-wise EV Registrations
- Top Vehicle Models
- CAFV Eligibility Analysis
- Interactive Slicers
  - Model Year
  - State
  - Manufacturer
  - Vehicle Type
  - CAFV Eligibility

---

## 💡 Business Insights

- Tesla is the leading EV manufacturer.
- Battery Electric Vehicles account for approximately **66%** of total registrations.
- Plug-in Hybrid Electric Vehicles account for approximately **34%**.
- California has the highest EV registrations.
- EV registrations show steady growth over recent years.
